# Bastio Privacy & Data Protection Policy

*Updated: October 11, 2026*

## 1. Core Data Protection Commitments
Bastio is engineered from the ground up for strict European and International data privacy standards:
- **No Training on Customer Data**: Customer prompts, LLM responses, and scanned data are **never** used to train foundation models.
- **Inline Processing**: Security scanning runs in the request path; latency varies with the enabled detectors and request.
- **Hosting and Providers**: The hosted Bastio Cloud backend uses EU infrastructure. Customer-selected model providers have their own processing locations and data-handling terms.

## 2. PII & Secret Redaction Mechanics
When PII masking (`POST /v1/pii/mask`) or Gateway PII filters are active:
1. Sensitive values (SSNs, IBANs, Credit Cards, API Keys, Emails, Phone Numbers) are replaced with synthetic placeholders (e.g. `<PII_EMAIL_1>`).
2. The mapping dictionary lives in volatile RAM during the request life cycle and is never persisted to disk or external databases.

## 3. Workspace Conversation Storage
Workspace currently persists conversation titles and messages. Its retention-days setting moves older messages to an analytics archive; it does not provide a conversation-content non-retention mode. Observability may also contain request and response bodies. Redaction alone is not a promise that confidential business information has been removed.

There is no default collection of anonymized Workspace conversation copies for training.

## 4. Data Processing Questions
For data-processing information or a Data Processing Addendum request, contact us.
