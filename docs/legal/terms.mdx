# Bastio Platform — Terms of Service

*Effective Date: August 6, 2026*

## 1. Overview & Acceptable Use
Bastio provides an open-source AI security gateway, standalone guardrail APIs, and managed enterprise private AI chat portals. By accessing Bastio Cloud or running self-hosted Bastio binaries, you agree to these terms.

## 2. API Usage & Plans
- **Self-hosted**: The open-source Bastio gateway is free to self-host. There is no free Bastio Cloud plan.
- **Trial**: New Bastio Cloud accounts start with a 14-day trial that includes 100,000 gateway requests, 100,000 governance events and 2 Workspace seats.
- **Paid Plans**: All prices are in euros (EUR) and exclude VAT. Cloud Core is €49 per month and includes 50,000 gateway requests and 50,000 governance events per month, 30-day data retention and 2 Workspace seats. Cloud Pro is €249 per month and includes 1,000,000 gateway requests and 1,000,000 governance events per month, 90-day data retention and 5 Workspace seats. Workspace without the gateway is €15 per seat per month. Enterprise pricing is set by contract.
- **Overages**: When a Cloud Core or Cloud Pro account reaches its included monthly quota, further requests are refused unless the account owner has enabled overage. With overage enabled, usage above the included quota is billed at €0.30 per 1,000 gateway requests and €0.10 per 1,000 governance events, metered and billed monthly, up to the monthly spending cap the owner sets.
- **Prohibited Conduct**: You may not attempt to reverse engineer detector signatures, bypass cryptographic licensing keys, or execute denial-of-service attacks against Bastio infrastructure.

## 3. Data Processing & Privacy Guarantees
- **Conversation storage**: Workspace conversation history is stored according to the configured Workspace data settings. Upstream model-provider retention terms are separate from Bastio’s storage settings.
- **Reversible PII Redaction**: PII token maps are held exclusively in volatile RAM during request lifetime and are destroyed immediately upon request completion.

## 4. Single-Binary Enterprise Licensing
Enterprise single-binary offline instances operate under Ed25519 cryptographic license verification (`bastio.lic`). License keys remain valid for the duration specified in your customer agreement and do not require external phone-home internet connectivity.
