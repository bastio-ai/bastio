---
title: Google Gemini
description: Route Gemini Developer API calls and asynchronous batches through Bastio.
---

Bastio registers a `gemini` provider client for the Gemini Developer API (`generativelanguage.googleapis.com`). Add a Google AI Studio provider key in Bastio, then use a Bastio application key in your SDK. Provider model access, quotas and usage charges stay with your Google account.

```python
from google import genai
from google.genai import types

client = genai.Client(api_key="YOUR_BASTIO_APPLICATION_KEY", http_options=types.HttpOptions(
    base_url="https://api.bastio.com/v1/google", api_version="v1beta"))
response = client.models.generate_content(model="gemini-2.5-flash", contents="Hello!")
```

`/v1/gemini` is an alias for `/v1/google`. Authentication accepts the SDK's `x-goog-api-key` header; Bastio sends the configured Google credential upstream. Use `X-Bastio-Proxy-Id` in SDK headers to select a particular routing proxy. Normalized Chat Completions also support the `gemini` provider through the gateway's translation pipeline.

Native inline/file generation batches, asynchronous embeddings, resumable JSONL uploads and result downloads are supported. See [Native batch APIs](/docs/batch-apis) for examples, retention, security coverage and limits. Uploaded image/audio bytes remain opaque to text detectors.

Self-hosters can override `GEMINI_BASE_URL` (default `https://generativelanguage.googleapis.com/v1beta`). A stable encryption key and PostgreSQL are required for asynchronous batch state.

Vertex AI uses separate project/region, IAM and batch-prediction APIs. Although the proxy schema reserves `vertex`, that service-account transport is not implemented by this Gemini Developer API client.
