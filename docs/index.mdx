# Bastio AI Security Platform

Bastio is an open-source AI security gateway and standalone guardrail API engine. It scans prompts, RAG documents, and agent tool calls for prompt injection, jailbreaks, PII, secrets, and dangerous shell commands in **under 20ms**.

Bastio operates across two core entry points powered by the exact same Go & ClickHouse threat engine:

1. **Pillar 1: Bastio AI Guardrails & Security Gateway (Developer APIs)**: Drop-in OpenAI/Anthropic SDK replacement (`base_url="https://api.bastio.com/v1"`) or direct REST APIs (`/v1/detect`, `/v1/pii/mask`, `/v1/guardrails/agent-action`).
2. **Pillar 2: Bastio Enterprise Private AI Portal**: Managed private chat portal for employees providing multi-provider LLM access behind strict zero-data retention and automated GDPR Article 30 audit trails.

## Major Platform Features

- **Inline Threat Intercept (under 20ms)**: Block prompt injection, DAN jailbreaks, toxicity, and secret leaks before requests leave your network.
- **Reversible PII & Secret Redaction**: Replace SSNs, Credit Cards, API Keys, and Emails with synthetic placeholders (`<PII_EMAIL_1>`) before hitting third-party LLMs, and restore output.
- **Autonomous Agent Action Guardrails**: Intercept dangerous shell commands (`rm -rf`), SQL injections, and path traversals in tool-call arguments before execution.
- **1-Click EU AI Act & ISO 42001 Compliance Auditor**: Download audit-ready evidence JSON reports summarizing controls for EU AI Act Articles 14, 15, 50 and ISO/IEC 42001:2023.
